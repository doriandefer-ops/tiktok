# Site La Cigalo — L'Esprit du Sud

Site vitrine + boutique en une seule page (`index.html`), sans dépendance ni serveur.

- **Ouvrir** : double-clic sur `index.html`, ou hébergement gratuit (GitHub Pages, Netlify, Render static site).
- **Produits, prix, email de commande** : bloc « À personnaliser » en bas de `index.html` (`PRODUITS`, `EMAIL_COMMANDES`).
- **Commande** : le panier génère un email récapitulatif vers `EMAIL_COMMANDES`. Pour du paiement en ligne, brancher Stripe Payment Links ou Shopify.
- **Images** : dossier `images/` (recadrées depuis le visuel Instagram). Remplace-les par de vraies photos produits dès que possible.
- **Newsletter** : le formulaire est visuel pour l'instant ; le relier à Brevo/Mailchimp pour collecter les emails.
- À compléter avant mise en ligne : mentions légales, CGV, politique de confidentialité.
