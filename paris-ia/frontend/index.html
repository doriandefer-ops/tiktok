Bilan vérifiable : le modèle face au marché

Backtest sans regard vers le futur : chaque semaine, le modèle est réentraîné sur le passé uniquement, puis comparé aux cotes moyennes du marché. Résultat actuel : le marché reste plus précis que le modèle seul (une erreur plus basse est meilleure), et les matchs où le modèle s'écarte nettement des cotes ne sont pas rentables. C'est pourquoi les probabilités publiées combinent le modèle (30 %) et le marché sans marge (70 %).
